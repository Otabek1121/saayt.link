# Forma project design guidance

Use the project-local skills from elayadesign/ai-design-skills:

- Read `.agents/skills/landing-page-design/SKILL.md` before creating or changing web UI, copy, typography, spacing, color or motion.
- Read `.agents/skills/figma-designer/SKILL.md` when working inside Figma. Do not create a Figma file merely to change this website.
- The upstream license is `.agents/skills/ELAYA-LICENSE`. Source and pinned blob checksums are recorded in `docs/design-system.md`.

Preserve existing functionality, authenticated ownership checks, published snapshots, public URLs, client content, QR codes and all six languages. Template photos are illustrative; do not invent reviews, prices, customer counts or business claims. Scope studio UI styles away from customer-authored brand colors. Validate with TypeScript, actual API integration tests, the production build and responsive browser checks before publishing. Follow the native Sites source and deployment workflow.
